# Support

For Crypto Research & Market Insights, contact keycustodian09@gmail.com or open a GitHub issue in this repository.

Include the plugin version, the question you asked, what went wrong, and whether current-data tools were available in your Claude session. Remove personal financial information, account identifiers and credentials before sharing an example. Never send seed phrases, private keys, passwords or identity documents. GitHub issues are public.

The author can review plugin instructions and documentation. Exchange account problems, KYC, deposits and withdrawals must be handled by the relevant exchange. There is no guaranteed response time or round-the-clock support.
